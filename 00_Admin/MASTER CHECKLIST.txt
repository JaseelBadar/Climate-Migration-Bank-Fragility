SECTION 6 -- TWITTER/X THREAD TEMPLATE
(post the day paper goes on SSRN)
======================================================================

Tweet 1:
New working paper: "Flood Shocks and the Two-Phase Deposit Cycle:
Evidence from Nighttime Lights."
631 Indian districts. 37 quarters. Panel IV using VIIRS satellite
data + EM-DAT floods + RBI deposits.
Main finding: floods create a 2-phase deposit cycle. Here is what
that means. [thread] [SSRN link]

Tweet 2:
When a flood hits, what happens to household savings?
Not what you expect. The effect is NOT immediate.
Deposits actually show a POSITIVE anticipatory saving pattern
in the quarter BEFORE the flood (t-1).

Tweet 3:
Then, 6 months after the flood (t-2), deposits fall sharply.
-0.70pp. Highly significant. Robust to Northeast exclusion,
winsorization, and state-level clustering.
This is the recovery phase. Households liquidate savings to
rebuild. Not panic. Delayed, rational, costly.

Tweet 4:
How did we identify this causally?
Instrument: flood exposure predicts nighttime lights (VIIRS),
which proxies for economic displacement.
First stage F = 34.7 under the conservative rule. Strong.

Tweet 5:
H2 (economic activity -> deposits contemporaneously): null.
p = 0.805.
This is NOT a failure. It is a prediction of the mechanism.
The effect is LAGGED, not contemporaneous. The null confirms
the timing story.

Tweet 6:
Robustness:
- Northeast exclusion: H3 strengthens (beta more negative)
- Winsorization: H3 stable (delta < 0.0002)
- State-level wild cluster bootstrap (999 iter): H3 p=0.034
- Longer lags (t-3): persistence confirmed (beta=-0.016, p<0.001)

Tweet 7:
Data pipeline: 38 scripts. VIIRS monthly composites (120 tiles,
2015-2024), EM-DAT flood events, RBI district deposits.
Composite district FE to resolve homonymous district problem
(7 district-name pairs spanning state boundaries).
Replication package: [GitHub link]

Tweet 8:
Policy implication:
If relief disbursement happens in t=0 (disaster quarter),
it arrives BEFORE peak household liquidity stress.
Peak stress is at t=2 (6 months later).
Disaster relief timing is systematically misaligned with
behavioral need.

Tweet 9:
For the disaster-banking and displacement-finance literature:
No identified paper estimates this two-phase cycle at
district-quarter frequency using satellite-based IV.
This is new.
Comments welcome. [SSRN link]
