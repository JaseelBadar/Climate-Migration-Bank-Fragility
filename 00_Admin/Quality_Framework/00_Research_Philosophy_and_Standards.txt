THE DAILY TEST
================================================================================

Every day, before making any research decision, ask:

1. "Is this decision pre-specified or am I chasing results?"
   → If chasing results: STOP. Document as exploratory.

2. "Can I defend this choice to a skeptical referee?"
   → If no: Strengthen justification or change approach.

3. "Does this bring me closer to 500 citations?"
   → If no: Eliminate or streamline.

4. "Would this pass the Nature transparency standard?"
   → If no: Add documentation, disclosure, or robustness check.

5. "Is this Ivy League quality or just 'good enough'?"
   → If just good enough: Iterate until excellent.

RESEARCH INTEGRITY PRINCIPLES
================================================================================

1. NEVER modify hypotheses after seeing results
   → Versions exist for audit trail, not result-fitting

2. NEVER drop observations without logging reason
   → ResearchLog.txt documents every data decision

3. NEVER report only significant results
   → Null findings are publishable if honestly pre-specified

4. NEVER hide weak identification
   → Weak IV? Report it, discuss limitations, suggest fixes

5. NEVER oversell contributions
   → We prove lights-deposits correlation, not causation from 
     deposits to banking crisis (that requires bank-level data we don't have)

6. ALWAYS disclose data limitations
   → 49% state-level flood coding = measurement error acknowledged
   → VIIRS = activity proxy, not direct population count

7. ALWAYS provide replication materials
   → GitHub repo with full code pipeline
   → README with exact package versions
   → Anyone can verify our results
