SECTION 3: THE BUG - DETAILED EXPLANATION
WHAT SCRIPT 13 DOES:

For 2023-24 file:

Detects NO ':Q' pattern in column names

Uses alternate logic: deposit_indices = range(7, ..., 3)

Extracts indices 7, 10, 13... → ✓ Deposit Amount columns

For 2017-22 and 2004-17 files:

Detects ':Q' pattern in column names (e.g., "2022-23:Q3")

Finds all columns with ':Q' → gets indices [4, 7, 10, 13...]

Extracts those indices directly → ✗ "Number of Reporting Offices"

SHOULD extract indices [5, 8, 11, 14...] → Deposit columns

THE ERROR:

python
# CURRENT (WRONG):
deposit_cols = [i for i, col in enumerate(df.columns) if ':Q' in str(col)]
for dep_idx in deposit_cols:
    temp = df[[state_col, district_col, df.columns[dep_idx]]].copy()
    # Extracts Column E (index 4) = Offices (87)
    # Should extract Column F (index 5) = Deposits (3,296)

# CORRECT:
quarter_label_cols = [i for i, col in enumerate(df.columns) if ':Q' in str(col)]
for q_idx in quarter_label_cols:
    dep_idx = q_idx + 1  # ← ADD THIS OFFSET
    temp = df[[state_col, district_col, df.columns[dep_idx]]].copy()
IMPACT:

ALL deposit data from 2004-2022 (72 quarters) is WRONG

Extracted "Number of Reporting Offices" instead of "Deposit Amount"

Offices are typically 20-200 (small integers)

Deposits are typically 500-5,000 Crores (for median districts)

This explains the anomalous values in 2022Q4 median (162 vs expected ~3,000)

UPDATE: 2023-24 file has different sub-headers:

Column G: "No. of Accounts" (in Thousands)

Column H: "Deposit Amount" (in ₹ Crores)

Script 13 for 2023-24 uses range(7, ..., 3) which gets index 7 = Column H (0-indexed).
Wait, Column H in pandas is index 7 only if there's no Column A offset.

PANDAS INDEXING CLARIFICATION:
If pd.read_excel() with no index_col, Column A becomes index 0 even if blank.
So:

Column A (blank) = Index 0

Column B (Region) = Index 1

...

Column H (Deposit Amount in 2023-24) = Index 7 ✓

But for 2023-24, the merged headers mean:

Index 5: "Sep-2025" (merged F:H)

Index 6: Unnamed (G)

Index 7: Unnamed (H) ← This is where Deposit Amount data lives

So range(7, ..., 3) gets indices 7, 10, 13...
These map to Columns H, K, N... which are the 3rd column in each quarter block.

In 2023-24: 3rd column = "Deposit Amount" ✓
In 2017-22: 3rd column would be index 6, 9, 12... = Credit (not Deposit)

Wait, the patterns are different:

2023-24 quarters start at Column F (index 5):

F (5): Offices

G (6): Accounts

H (7): Deposit ← range(7, ..., 3) gets this ✓

2017-22 quarters start at Column E (index 4):

E (4): Offices ← Script wrongly gets this

F (5): Deposit ← Should get this

G (6): Credit

So the fix is confirmed: dep_idx = q_idx + 1
